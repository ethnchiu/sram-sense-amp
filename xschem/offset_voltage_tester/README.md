## SRSAR Measurement for Sense Amplifier Offset Voltage

This xschem project uses the ngspice control language to perform an offset voltage simulation of the sense amplifier. The offset voltage tester utilizes a smart resettable successive approximation register (SRSAR) algorithm to obtain a comparator's rising and falling offset voltage [1].

[1] H. Omran, “Fast and accurate technique for comparator offset voltage simulation,” Microelectronics Journal, vol. 89, pp. 91–97, Jul. 2019, doi: [https://doi.org/10.1016/j.mejo.2019.05.004](https://doi.org/10.1016/j.mejo.2019.05.004).
